# AI Resume Analyzer

Full-stack AI-powered resume analysis app with ATS scoring, skill extraction, Gemini AI feedback, charts, and PDF export.

## Tech Stack

| Layer | Stack |
|-------|-------|
| Frontend | React, Vite, Tailwind, Chart.js, React Router |
| Backend | FastAPI, MongoDB (Motor), JWT, spaCy, pdfplumber, Gemini, ReportLab |
| Deploy | Vercel (frontend), Render (backend), MongoDB Atlas (database) |

## Features

- PDF resume upload and parsing
- 7-dimension ATS scoring with grades and recommendations
- Skill extraction (spaCy + skills dataset)
- Gemini AI career feedback (with rule-based fallback)
- Interactive charts (dashboard trends, report breakdowns, job match)
- PDF report export
- Job description comparison
- Auth, history, settings (per-user Gemini API key)

## Local Development

### Prerequisites

- Python 3.12+
- Node.js 18+
- MongoDB (local or Atlas)

### 1. Backend

```bash
# From project root
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux

pip install -r requirements.txt
python -m spacy download en_core_web_sm

copy .env.example .env         # edit MONGODB_URL, JWT_SECRET_KEY, GEMINI_API_KEY
cd backend
..\venv\Scripts\uvicorn main:app --reload --port 8000
```

API: http://localhost:8000  
Docs: http://localhost:8000/docs

### 2. Frontend

```bash
cd frontend
npm install
copy .env.example .env         # VITE_API_URL=http://localhost:8000/api
npm run dev
```

App: http://localhost:5173

## Deployment

See **[DEPLOYMENT.md](DEPLOYMENT.md)** for the full step-by-step guide (MongoDB Atlas → GitHub → Render → Vercel).

Quick overview:

```
┌─────────────┐     HTTPS      ┌──────────────┐     HTTPS      ┌────────────────┐
│   Vercel    │ ─────────────► │    Render    │ ─────────────► │ MongoDB Atlas  │
│  (React UI) │                │  (FastAPI)   │                │   (Database)   │
└─────────────┘                └──────────────┘                └────────────────┘
```

### Step 1 — MongoDB Atlas (free tier)

1. Create account at https://www.mongodb.com/cloud/atlas
2. Create a **free M0 cluster**
3. Database Access → add user with password
4. Network Access → add `0.0.0.0/0` (allow from anywhere) for Render
5. Connect → Drivers → copy connection string, e.g.:
   ```
   mongodb+srv://USER:PASSWORD@cluster0.xxxxx.mongodb.net/resume_analyzer?retryWrites=true&w=majority
   ```

### Step 2 — Push code to GitHub

```bash
git init
git add .
git commit -m "Initial commit — AI Resume Analyzer"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/resume-analyzer.git
git push -u origin main
```

### Step 3 — Deploy backend on Render

1. Go to https://render.com → **New** → **Blueprint**
2. Connect your GitHub repo
3. Render reads `render.yaml` automatically
4. Set these **secret** environment variables when prompted:

   | Variable | Value |
   |----------|-------|
   | `MONGODB_URL` | Your Atlas connection string |
   | `GEMINI_API_KEY` | Your Google Gemini API key |
   | `CORS_ORIGINS` | `https://YOUR-APP.vercel.app` (set after Vercel deploy) |

5. Deploy — first build takes ~5–10 min (spaCy model download)
6. Note your API URL: `https://resume-analyzer-api.onrender.com`

**Health check:** `https://resume-analyzer-api.onrender.com/api/health`

> **Note:** Free Render services spin down after inactivity (~50s cold start). Persistent disk (`/var/data`) stores uploads and PDFs across restarts.

### Step 4 — Deploy frontend on Vercel

1. Go to https://vercel.com → **Add New Project**
2. Import your GitHub repo
3. Configure:
   - **Root Directory:** `frontend`
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Environment Variables:

   | Key | Value |
   |-----|-------|
   | `VITE_API_URL` | `https://resume-analyzer-api.onrender.com/api` |

5. Deploy

### Step 5 — Link frontend and backend

1. Copy your Vercel URL (e.g. `https://resume-analyzer.vercel.app`)
2. In **Render** → your service → **Environment** → update:
   ```
   CORS_ORIGINS=https://resume-analyzer.vercel.app
   ```
3. Redeploy the Render service

### Step 6 — Verify production

- [ ] Frontend loads at Vercel URL
- [ ] Register / login works
- [ ] Upload PDF and run full analysis
- [ ] PDF download works
- [ ] `/api/health` returns `"status": "healthy"`

## Environment Variables Reference

### Backend (Render)

| Variable | Required | Description |
|----------|----------|-------------|
| `MONGODB_URL` | Yes | MongoDB Atlas connection string |
| `JWT_SECRET_KEY` | Yes | Auto-generated by Render blueprint |
| `GEMINI_API_KEY` | Recommended | Server-side Gemini key (users can also set their own in Settings) |
| `CORS_ORIGINS` | Yes | Comma-separated frontend URLs |
| `UPLOAD_DIR` | No | Default `/var/data/uploads` on Render |
| `REPORTS_DIR` | No | Default `/var/data/reports` on Render |
| `APP_ENV` | No | Set to `production` on Render |
| `DEBUG` | No | Set to `false` on Render |

### Frontend (Vercel)

| Variable | Required | Description |
|----------|----------|-------------|
| `VITE_API_URL` | Yes | Render API URL with `/api` suffix |

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/register` | Create account |
| POST | `/api/login` | Login |
| GET | `/api/me` | Current user |
| POST | `/api/upload` | Upload PDF |
| POST | `/api/parse` | Parse resume |
| POST | `/api/ats` | ATS score |
| POST | `/api/ai/feedback` | Gemini feedback |
| POST | `/api/analyze` | Full analysis + report |
| POST | `/api/compare` | Job description comparison |
| GET | `/api/history` | Report history |
| GET | `/api/report/{id}` | Report details |
| GET | `/api/download/{id}` | Download PDF |
| DELETE | `/api/report/{id}` | Delete report |
| GET | `/api/health` | Health check |
