# Production Deployment Guide

Deploy **AI Resume Analyzer** to MongoDB Atlas + Render + Vercel.

---

## Step 1 — MongoDB Atlas (Database)

1. Go to [mongodb.com/cloud/atlas](https://www.mongodb.com/cloud/atlas) and sign up / log in.
2. **Create** → **Shared (Free M0)** cluster.
3. **Database Access** → **Add New Database User**
   - Username + strong password (save these).
   - Built-in role: `Atlas admin` or `Read and write to any database`.
4. **Network Access** → **Add IP Address** → **Allow Access from Anywhere** (`0.0.0.0/0`)
   - Required so Render can connect.
5. **Database** → **Connect** → **Drivers** → copy connection string:
   ```
   mongodb+srv://USERNAME:PASSWORD@cluster0.xxxxx.mongodb.net/resume_analyzer?retryWrites=true&w=majority
   ```
   Replace `USERNAME`, `PASSWORD`, and ensure `/resume_analyzer` is the database name.

## Step 3 — Deploy Backend on Render

1. Go to [render.com](https://render.com) → sign up with GitHub.
2. **New** → **Blueprint**.
3. Connect the `resume-analyzer` repository.
4. Render detects `render.yaml` and shows the `resume-analyzer-api` service.
5. When prompted, enter **secret** environment variables:

   | Key | Value |
   |-----|-------|
   | `MONGODB_URL` | Your Atlas connection string from Step 1 |
   | `GEMINI_API_KEY` | Your Google Gemini API key ([aistudio.google.com](https://aistudio.google.com/apikey)) |
   | `CORS_ORIGINS` | `https://YOUR-APP.vercel.app` *(update after Step 4)* |

6. Click **Apply** / **Deploy**.
7. Wait ~5–10 minutes for the first build (spaCy model download).
8. Copy your live API URL, e.g.:
   ```
   https://resume-analyzer-api.onrender.com
   ```
9. Verify: open `https://resume-analyzer-api.onrender.com/api/health`  
   Expected: `"status": "healthy"` and `"connected": true`.

> **Free tier note:** Render free services sleep after ~15 min idle (cold start ~30–60s). Uploads/PDFs use ephemeral disk and may not survive redeploys. Upgrade to Render Starter + persistent disk for production storage.

---

## Step 4 — Deploy Frontend on Vercel

1. Go to [vercel.com](https://vercel.com) → sign up with GitHub.
2. **Add New** → **Project** → import `resume-analyzer` repo.
3. Configure:

   | Setting | Value |
   |---------|-------|
   | **Root Directory** | `frontend` |
   | **Framework Preset** | Vite |
   | **Build Command** | `npm run build` |
   | **Output Directory** | `dist` |

4. **Environment Variables**:

   | Key | Value |
   |-----|-------|
   | `VITE_API_URL` | `https://resume-analyzer-api.onrender.com/api` |

5. Click **Deploy**.
6. Copy your Vercel URL, e.g.:
   ```
   https://resume-analyzer.vercel.app
   ```

---

## Step 5 — Link Frontend ↔ Backend (CORS)

1. **Render** → `resume-analyzer-api` → **Environment**.
2. Set / update:
   ```
   CORS_ORIGINS=https://resume-analyzer.vercel.app
   ```
   For multiple origins (preview + production):
   ```
   CORS_ORIGINS=https://resume-analyzer.vercel.app,https://resume-analyzer-git-main-youruser.vercel.app
   ```
3. **Save Changes** → Render redeploys automatically.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| CORS error in browser | Add exact Vercel URL to `CORS_ORIGINS` on Render, redeploy |
| `503` / slow first request | Render free tier cold start — wait 30–60s |
| Database connection failed | Check Atlas IP whitelist (`0.0.0.0/0`) and connection string |
| Build fails on spaCy | Render build runs `python -m spacy download en_core_web_sm` automatically |
| Gemini returns fallback text | Set `GEMINI_API_KEY` on Render or in app Settings |
| Upload works locally but not prod | Check Render logs; ensure `MONGODB_URL` is set |
